QDStarIC-705 · D-STAR Terminal Mode

Controlador de escritorio y gateway D-STAR integrado para el Icom IC-705. Enlaza reflectores, mira quién está en el aire y desde dónde, y sigue las posiciones D-PRS y las estaciones meteorológicas, desde Windows o Linux.

Software libre · GPL-3.0

QDStar es una aplicación muy nueva. Está probada en mi Icom IC-705 con el firmware 1.40. Si tienes algún problema, búscame en DMR en el grupo 214 o en D-STAR en el reflector 214, y por favor abre una issue en GitHub contando qué ha pasado.

Funciones

Por WiFi

Habla con la radio con el protocolo de red de Icom (control y CI-V, sin audio). No hace falta wfview.

Gateway integrado

Terminal Mode por USB con su propio gateway: DPlus (REF), DCS (DCS, XLX) y DExtra (XRF). Sin DStarRepeater ni ircDDBGateway.

Modos INT y EXT

Usa el gateway interno de la radio con un servidor G3, o enlaza reflectores desde el PC. Se cambia con un clic.

Pantalla del reflector

Estado y nodos del reflector, la estación en el aire con nombre, localidad, distancia y rumbo, y los últimos oídos del reflector.

D-PRS

Posiciones, objetos, ítems e informes meteorológicos recibidos, también los reenviados. Gestiona tu propia baliza D-PRS desde la app.

Meteo

Una ficha por cada estación meteorológica D-PRS: temperatura, humedad, presión, lluvia y viento.

Histórico

Se guarda cada pasada: hora, indicativo, nombre, reflector, duración, mensaje y localidad.

Windows y Linux

Instalador para Windows; .deb, AppImage y tar.gz para Linux x86-64 y ARM64 (Raspberry Pi y otros mini PC).

Windows 10/11

64 bits

QDStar-x.y.z-windows-x64-setup.exe Recomendado

Un instalador que añade QDStar al menú Inicio. Para actualizar, ejecuta el instalador de la versión nueva: se conservan tus ajustes.

QDStar-x.y.z-windows-x64-portable.zip

Sin instalación: descomprímelo en cualquier carpeta, o en un pendrive, y ejecuta qdstar.exe.

Linux en un PC

x86-64 / amd64

qdstar_x.y.z_amd64.deb Recomendado

Para Debian, Ubuntu, Linux Mint y sus derivadas. Se instala con sudo apt install ./qdstar_x.y.z_amd64.deb.

QDStar-x.y.z-x86_64.AppImage

Funciona en casi cualquier distribución (Fedora, Arch, openSUSE…). Dale permiso de ejecución y ábrelo.

QDStar-x.y.z-linux-amd64.tar.gz

El programa en archivos sueltos, para descomprimir donde quieras.

Linux en ARM

arm64 / aarch64: Raspberry Pi 4/5 y otros mini PC con sistema de 64 bits

qdstar_x.y.z_arm64.deb Recomendado

Para Raspberry Pi OS (64 bits, bookworm o posterior), Debian y Ubuntu.

QDStar-x.y.z-aarch64.AppImage

Para otras distribuciones ARM64.

QDStar-x.y.z-linux-arm64.tar.gz

El programa en archivos sueltos.

x.y.z es el número de versión. ¿No sabes qué Linux tienes? Ejecuta uname -m: x86_64 es PC (amd64) y aarch64 es ARM64. La instalación y la configuración de la radio se explican en el manual.
