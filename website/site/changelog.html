Changelog

What is new and fixed in each version. The files of every version are on GitHub releases.

0.5.1 2026-09-27

  • Settings: new Note (/…) field to change the note after your call sign (e.g. /705) without going through the radio's menus. QDStar writes it to the radio's MY call sign and confirms it in the log.

0.5.0 2026-09-27

  • Linux AppImage: QDStar offers to install itself for your user. It moves to ~/.local/bin/QDStar.AppImage and appears in the applications menu, with no administrator rights. Help has Install for this user… and Uninstall QDStar….
  • Linux AppImage: Update now downloads the new version, checks its SHA-256, replaces the old one and restarts QDStar. No more replacing the file by hand.
  • The manual explains the Linux installation in more detail.

0.4.8 2026-09-27

  • A long over that reaches QDStar in bursts (short gaps from the reflector or the network) is now a single entry in the history and in the log, with its full duration. Its message is logged once.

0.4.7 2026-09-26

  • Linux (AppImage, .deb, tar.gz): the update link and the Download button open the browser again.

0.4.6 2026-09-26

  • The window can no longer be maximized or go full screen.
  • D-PRS reports without a symbol no longer show broken characters.

0.4.5 2026-09-26

  • The mode buttons show a small LED on the active mode.
  • The mode warning is a single ⚠ sign; its tooltip lists what to check.

0.4.4 2026-09-26

  • Only one copy runs at a time: a second launch brings the open window to the front.

0.4.3 2026-09-26

  • D-PRS reports show the right relaying station.
  • Short data-only overs are detected.
  • Weather cards stay current: a repeated report is accepted again after 5 minutes.

0.4.2 2026-09-26

  • The screen keeps its 4:3 size in a short window; the tabs shrink instead.

0.4.1 2026-09-26

  • Sharper text on the screen and the weather cards.
  • About shows the author's location.

0.4.0 2026-09-26

  • New D-PRS tab: positions, objects, items and weather reports, with distance, direction and the relaying station.
  • New Weather tab: a card per weather station, nearest first.
  • Both tabs can be turned off in the settings.
  • Distances also use the radio's internal GPS when it is on.

0.3.9 2026-09-26

  • More readable secondary text on the screen.

0.3.8 2026-09-26

  • Start-up screen with progress.

0.3.7 2026-09-26

  • The new version notice is a link next to the mode buttons.

0.3.6 2026-09-26

  • Larger last heard list (three stations) and footer.

0.3.5 2026-09-26

  • D-PRS positions at 0°, 0° (radios without a GPS fix) are ignored.
  • The station's locator is shown in the screen footer.
  • Narrower window (420 px).

0.3.4 2026-09-26

  • EXT mode relinks the last reflector on start.
  • Distance and direction box on the screen, and a distance column in the history.

0.3.3 2026-09-26

  • Checks for new versions on start-up and daily, with Download, Later or Skip this version.

0.3.2 2026-09-26

  • Received D-PRS positions fixed: positions, objects, items and weather reports.

0.3.1 2026-09-26

  • Narrower window.
  • The settings only show the ircDDBGateway fields when it is selected.

0.3.0 2026-09-26

  • DStar705 is now QDStar; settings and data migrate automatically.
  • English and Spanish interface.
  • D-PRS: position and distance of the station on air; manage your own D-PRS beacon.
  • Windows installer: update, uninstall and optional removal of user data.
  • Names and locations work on Windows.

0.2.1 2026-09-26

  • Your own overs appear in the reflector's last heard list right away.

0.2.0 2026-09-26

  • First public version, as DStar705: IC-705 controller over WiFi and built-in gateway with DPlus, DCS and DExtra.
